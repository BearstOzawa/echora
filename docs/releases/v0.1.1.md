Echora 0.1.1 建立了原生客户端的首轮发布链路，并完成 Web 与 Cloud 部署流程的稳定性改进。

## 本次更新

- 新增 macOS Apple Silicon、macOS Intel、Windows x64 与 Android 通用安装包。
- 建立版本一致性检查、自动化构建、SHA-256 校验和 GitHub Release 草稿流程。
- 修复 Web 与 Echora Cloud 的部署登记和版本读取链路。
- 更新项目架构、开发约定与安全报告文档。

## 已知限制

- macOS DMG 尚未完成 Apple Developer ID 签名与公证，首次打开可能需要按安装说明移除隔离标记。
- Windows 安装包尚未完成代码签名，系统可能显示信誉提示。
- iOS 仅提供未签名 IPA 和模拟器构建，不属于可直接安装的正式版本。
